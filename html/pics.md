# FURI-LRC 网站截图清单

把截图放到 `html/assets/screenshots/`，文件名保持如下。当前网站已经预留这些位置；图片放进去后无需改 HTML。

## 必截

1. `player-main.png`
   - 内容：`furi-lrc-player.py` 主窗口，正在播放一首歌，能看到封面/标题/播放控制/播放列表。
   - 建议尺寸：至少 1400x900，深色界面完整显示。

2. `gui-editor.png`
   - 内容：`furi-lrc-gui.py` 编辑器全貌，打开一个 `.flproj`，能看到左侧歌词列表、右侧编辑区和底部波形。
   - 建议尺寸：至少 1600x1000。

3. `overlay-desktop.png`
   - 内容：桌面透明歌词悬浮窗，最好有日文、假名和中文三层文本，并显示正在高亮的一行。
   - 建议尺寸：至少 1600x900。可以截桌面一角，但不要让背景过乱。

## 可选增强

4. `gui-units.png`
   - 内容：GUI 中逐假名/逐单位时间表或打拍对齐窗口，突出“逐假名时间轴”能力。
   - 建议尺寸：1200x800。

5. `player-playlist.png`
   - 内容：播放器的播放列表、循环模式、歌词偏移或右键菜单。
   - 建议尺寸：1200x800。

## 截图处理建议

- 不要压缩得太狠，PNG 或高质量 WebP 都可以；如果改成 WebP，需要同步改 `index.html` 里的文件名。
- 尽量使用同一套测试歌曲，让截图风格统一。
- 截图里避免出现私人绝对路径、系统通知、聊天窗口和未授权的个人信息。
